# Lente VR

Foto e vídeo do celular em VR lado a lado para visor Shinecon / Cardboard.
Correção de lente no modelo do Google Cardboard (cardboard-vr-display).

## App Android

Baixe o APK mais recente no celular:
https://github.com/Eduardrj/vr/releases/latest/download/LenteVR.apk

O app captura um único app (YouTube, galeria etc.) e mostra em VR lado a lado.
Requer Android 14 ou mais novo. O código fica em `android/` e o APK é gerado
automaticamente pelo GitHub Actions a cada alteração.
